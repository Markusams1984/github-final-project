# Simple Interest Calculator

## About the Project
A command-line tool written in Bash that calculates simple interest based on a principal amount, annual rate of interest, and time period in years. 

## Formula
Simple interest is calculated using the standard mathematical formula:
$$ Simple Interest = \frac{p \times t \times r}{100} $$

Where:
- **p**: Principal amount
- **t**: Time period in years
- **r**: Annual rate of interest

## Getting Started
To run this project locally, clone the repository and execute the script from your terminal.

### Prerequisites
- A terminal environment (Bash/Zsh).
- `bc` (Basic Calculator) installed on your system for floating-point math.

Run the script and follow the interactive prompts:
